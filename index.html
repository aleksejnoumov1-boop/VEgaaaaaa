FAQ

Есть вопросы? Ловите ответы.

Собрали всё что спрашивают чаще всего — чтобы ты мог начать играть без лишних заморочек.

Как установить Vega?

Скачай лаунчер по кнопке выше, запусти его, введи никнейм и нажми «Играть». Всё остальное лаунчер сделает автоматически.

Нужна ли лицензия Minecraft?

Для игры лицензия не требуется, скачиваете лаунчер и играете.

Как проверить обновления?

Все обновления применяются автоматически при следующем запуске лаунчера. Никаких ручных действий не нужно.

Какая версия Java нужна?

Необходима Java 21. Скачай Temurin 21 с adoptium.net и установи с галочкой «Add to PATH».

Лаунчер не запускается. Что делать?

Убедись что Java 21 установлена и запусти от имени администратора. При проблемах обратись в поддержку.
